0. 작업 배경

현재 “주민 수요·우선과제 분석” 탭은 가상값일 때는 화면이 자연스럽지만, 실제 조사값을 연결하면 아래 문제가 발생함.

섹션 3 마을별 비교가 비어 있음

자유의견 키워드가 비의미적이거나 거의 추출되지 않음

자유의견 대표 문장 박스가 공란에 가까움

하단 “AI 데이터 분석 기반 운영계획 반영 방향(안)”이 공란

일부 범례가 데이터 없이 고정 노출됨

실제 응답 카테고리와 코드상 기대 카테고리가 다를 수 있음

이 문제는 데이터를 바꾸는 방식으로 해결하지 않고,
실제값 유지 + 예외처리/fallback/UI 보완 방식으로 해결해야 함.

실제 조사값은 그대로 유지하되, 결측·희소·불균형 데이터에서도 비어 보이지 않는 조사분석형 화면으로 고도화하라. 숫자를 바꾸지 말고, fallback·동적 렌더링·키워드 정제·자동 해석 템플릿으로 해결하라.
