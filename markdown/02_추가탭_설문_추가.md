전략 대시보드 신규 탭 2개 추가 구현 — Q28~Q36 반영 개정판

전제

이번 개정판은 주민 설문에 추가된 Q28~Q36를 반영하여,
기존 탭 2개 설계를 정밀형에 가깝게 보정하는 작업이다.

기존 탭명은 유지한다.

탭1: 사회혁신 프로그램 실행현황

탭2: 링커·주민참여 실행기반

주민 설문 PDF 기준으로 전체 문항 번호는 아래 구조를 따른다.
기존 대화에서 사용한 일부 번호와 달리, 최신 기준은 반드시 PDF 기준 번호를 사용한다.
즉, 구현 시 매핑은 아래 PDF 번호 기준으로 다시 맞춘다.

기존 기대/참여의향 추정형이 아니라,
Q34 활동 가능 분야 + Q35 시간대 + Q36 교육 후 참여 의향을 포함한 직접형 분류로 재설계한다.
