설문통계 탭 보강 — 총괄표 + 핵심 분포 차트 추가

1. 작업 목적

현재 설문통계 탭에 설문 집계 총괄 정보와 Q28~Q36 세부 분포를 보강한다.
목표는 다음 두 가지다.

운영계획서 작성 시 바로 참고 가능한 총괄표를 설문통계 탭 안에 배치

차트로 구현 가능한 항목은 최대한 시각화하여 마을별/전체 경향을 한눈에 볼 수 있게 함

중요:

주민 설문 실제값 기준으로 집계

임의 보정 없이 실제 응답 데이터만 사용

설문통계 탭 내에서 **“총괄표 + 차트”**가 함께 보이도록 구성

UI는 현재 Admin Pro 스타일 유지

데이터가 부족한 경우 공란이 아니라 응답 없음, 표본 부족, 비교 유보 등으로 처리

12. 최종 성공 기준

이 작업이 성공한 상태는 아래와 같음.

설문통계 탭만 봐도 기본 응답 구조를 한눈에 알 수 있을 것

전체/만리포/천리포의 상위 수요 차이를 바로 볼 수 있을 것

Q28~Q36의 전체/마을별 분포를 차트로 모두 확인할 수 있을 것

운영계획서 작성 시 총괄표와 차트를 바로 참고할 수 있을 것

실제값 기준으로 집계되고, 데이터 부족 시도 공란 없이 자연스럽게 보일 것

13. 안티그라피티에게 마지막 한 줄

설문통계 탭에 “설문 집계 총괄표”와 Q28~Q36 전체/만리포/천리포 분포 차트를 추가해, 주민 설문 구조와 우선 수요를 한눈에 볼 수 있는 보고서형 통계 탭으로 보강하라.
