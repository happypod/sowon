4. 대시보드 연동 방식

워크숍 시트는 주민 설문 시트와 섞지 말고,
공란 섹션과 하단 운영방향에만 보완 레이어로 사용한다.

섹션 3. 마을별 우선 필요영역 지수 비교
현재 문제

주민 설문만으로 마을별 비교값이 부족하여 차트가 비어 있음

수정 방향

차트 대신 또는 차트 하단에 워크숍 기반 마을별 우선 이슈 요약을 붙일 것

표시 방식 1안

작은 2열 표 또는 카드형 요약

예:

만리포: 의료·이동, 돌봄, 경관·환경

천리포: 의료·이동, 돌봄, 생활환경

공통: 주차, 쓰레기, 시설 노후화

표시 방식 2안

막대차트 대신 “상위 theme_lv1 빈도” 기준으로 마을별 Top 3 요약

주석

주: 주민 설문 비교가 제한된 구간은 워크숍 보완 의견을 함께 반영함.

우선 검토 분야 매트릭스

이 매트릭스는 설문 빈도 + 워크숍 반복 언급 + 실행 검토 판단을 반영한

8. 최종 성공 기준

이번 수정이 성공한 상태는 아래와 같음.

주민 설문 실제값은 그대로 유지될 것

공란 4개 섹션이 워크숍 보완 데이터로 자연스럽게 채워질 것

주민 설문과 워크숍 결과가 혼동되지 않을 것

운영계획서에 “주민 설문 + 워크숍 의견을 종합한 분석”으로 설명 가능할 것

마지막 표가 더 이상 공란이 아니고 실제 운영계획 반영 문구를 보여줄 것

9. 안티그라피티에게 마지막 한 줄

주민 설문 원자료는 수정하지 말고, 워크숍 결과를 WORKSHOP_CODING 시트로 구조화해 공란 섹션을 보완하라. 이 탭은 설문 단독 화면이 아니라, 설문과 현장 의견을 종합해 운영계획에 반영하는 조사분석형 화면이어야 한다.
